
# Evolution of Trust Multiplayer

Free deployment options:

## Render
1. Create GitHub repository
2. Upload files
3. Create a new Web Service on Render
4. Build command: npm install
5. Start command: npm start

The app creates shareable room URLs:
https://your-app.onrender.com/?room=abc123

Rules:
- Cooperate/Cooperate = 3 each
- Cooperate/Compete = 0 and 5
- Compete/Compete = 1 each
